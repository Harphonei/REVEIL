# REVEIL

> …Have we met before?

เกม Dark Fantasy RPG แบบพิกเซลอาร์ต สำรวจโลกจากมุมมองด้านบน และเอาชีวิตรอดจากการต่อสู้แบบ Bullet Hell

คุณตื่นขึ้นในป่าที่ไม่รู้จัก โดยไร้ความทรงจำเกี่ยวกับตัวเอง เดินทางผ่านเหมือง ป่าประหลาด และวิหารร้าง เพื่อค้นหาคำตอบว่าคุณเป็นใคร และเหตุใดเหล่าผู้ที่พบเจอจึงดูเหมือนรู้จักคุณ

พัฒนาด้วย **Java · Swing · Java2D · Maven** สำหรับโครงงานวิชา Object-Oriented Programming

## ดาวน์โหลดและเปิดเกม

ต้องมี **Java 17 ขึ้นไป** และใช้คีย์บอร์ดกับเมาส์ แนะนำให้เล่นบน Windows

1. [ดาวน์โหลดโปรเจกต์เป็น ZIP](https://github.com/Harphonei/REVEIL/archive/refs/heads/main.zip)
2. แตก ZIP ทั้งหมดก่อนเปิดเกม
3. เปิดโฟลเดอร์ `dist` แล้วเปิด `REVEIL.jar`

หากดับเบิลคลิกแล้วเกมไม่เปิด ให้เปิด Terminal ในโฟลเดอร์หลักที่มี `pom.xml` แล้วใช้:

```bash
java -jar dist/REVEIL.jar
```

**เก็บโฟลเดอร์ `src/main/resources` ไว้ในตำแหน่งเดิม** เพราะ JAR ใน `dist` โหลดภาพและฟอนต์จากโฟลเดอร์นี้ ดาวน์โหลดเฉพาะ JAR จะเปิดเกมได้ไม่ครบ

## วิธีเล่น

สำรวจแมพทั้ง 5 ด่าน พูดคุย ตรวจดูสิ่งของ และต่อสู้กับบอสประจำด่าน ในฉากต่อสู้ คุณควบคุมหัวใจสีแดงเพื่อหลบการโจมตี พร้อมยิงสวนกลับขึ้นไปหาบอส

| ปุ่ม | การใช้งาน |
| --- | --- |
| W / A / S / D | เดินในแมพ / เคลื่อนหัวใจหลบการโจมตี |
| Shift ค้าง | วิ่งขณะสำรวจ |
| F | สำรวจวัตถุเมื่อมีข้อความให้กด |
| คลิกขวาค้าง | ยิงโจมตีในฉากต่อสู้ |
| E | Heavy Attack — รวบรวมพลังแล้วโจมตี หลังปลดล็อก |
| Q | Ultimate — เพิ่มพลังการยิงเป็นเวลา 5 วินาที หลังปลดล็อก |
| Enter / Space / คลิกซ้าย | แสดงข้อความให้ครบ แล้วกดอีกครั้งเพื่ออ่านต่อ |
| Tab หรือปุ่ม Skip > | ข้ามฉากเนื้อเรื่อง |
| Esc | เปิดหรือปิดเมนูพักเกม |

ดูคำแนะนำในเกมเพิ่มเติมได้ที่ **How to Play** บนหน้าหลัก เมนูพักเกม และหน้า You Died

## การเล่นต่อและการลองใหม่

- **New Game** เริ่มเรื่องใหม่
- เมื่อออกสู่หน้าหลักหรือปิดหน้าต่างระหว่างเล่น เกมจะบันทึกด่านปัจจุบันไว้
- **Continue** กลับไปเริ่มที่ทางเข้าของด่านที่บันทึกไว้ และเล่นเนื้อเรื่องของด่านนั้นใหม่ ไม่ได้กลับสู่ตำแหน่งที่ยืนค้างไว้
- เมื่อตาย เลือก **Retry** เพื่อเริ่มการต่อสู้เดิมใหม่
- เมื่อเล่นจบ จะปลดล็อก **Boss Rematch** สำหรับเลือกสู้กับบอสในระดับที่ยากขึ้น การปลดล็อกจะถูกบันทึกไว้บนเครื่องนั้น

## เปิดโปรเจกต์เพื่อพัฒนา

ใช้ **JDK 17 ขึ้นไป** เปิดโฟลเดอร์ที่มี `pom.xml` เป็น Maven Project ใน NetBeans แล้ว Run Project โดยคลาสเริ่มต้นคือ `finalgame.GameApplication`

หากติดตั้ง Maven แล้ว สามารถ Build และเปิดเกมจาก Terminal ได้:

```bash
mvn clean package
java -jar target/REVEIL.jar
```

| ตำแหน่ง | เนื้อหา |
| --- | --- |
| `src/main/java/finalgame` | โค้ดเกม ตัวละคร บอส รูปแบบโจมตี แมพ เนื้อเรื่อง และ UI |
| `src/main/resources/finalgame` | ภาพพิกเซล สไปรต์ ขอบเขตการเดิน และฟอนต์ |
| `dist/REVEIL.jar` | ไฟล์เกมที่ Build ไว้พร้อมเปิด |
| `pom.xml` | การตั้งค่า Maven และเวอร์ชัน Java |
