## เปิดเกม

ใช้Java17ขึ้นไป แตกZIPทั้งโฟลเดอร์ เปิด dist/REVEIL.jar หรือรันคำสั่งจากโฟลเดอร์REVEIL:

```text
java -jar dist/REVEIL.jar
```

ต้องเก็บsrc/main/resourcesไว้คู่โฟลเดอร์distตามที่แตกZIPมา JARขนาดเล็กจะอ่านภาพและฟอนต์จากตำแหน่งนี้ เปิดโฟลเดอร์REVEILที่มีpom.xmlในNetBeansได้ตามเดิม
